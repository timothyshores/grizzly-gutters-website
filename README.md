# Grizzly Gutters

Single-page website for a Salt Lake City gutter contractor.

**Live: https://timothyshores.github.io/grizzly-gutters-website/**

Static HTML and CSS. No build step, no framework, no dependencies. Everything
is in `index.html`.

Deployed by GitHub Pages from the `main` branch, root folder. Push to `main`
and the live site updates in about a minute.

The contact form posts to Formspree.
